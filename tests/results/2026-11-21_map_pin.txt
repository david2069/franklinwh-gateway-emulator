# #365 Web UI: pin the map so the gateway cards scroll beneath it, 2026-11-21

Base: origin/main 0fcbbb8. No owner design for this in private/ui-design; the toggle follows the
header's Compact and Map buttons.

Design: a **Pin** button beside **Map** (shown only while the map is on, aria-pressed like Compact
and Map). Pinned, `.fleet-map` is `position: sticky; top: 0; z-index: 20` inside the cards' column,
so it stays at the top of the window while the cards scroll beneath it; the drawer is z-index 30,
the splash 50; `.fleet-map` keeps `isolation: isolate`, so Leaflet's 400-1000 stay inside it.
Narrow screens: pinned, not disabled, with the map's height capped at min(380px, 40vh)
(min(260px, 40vh) at 600 px wide or less), which also covers short windows such as a phone in
landscape. Remembered as localStorage `emulator.mapPinned` through the existing setView (try/catch).
setView calls resizeFleetMap (map.js: `_map.invalidateSize()`) after a pin change, since the map's
height changes and Leaflet measures only when told.
